# sl-skill

我自用 & 供大家娱乐使用的 [Claude Code / Agent Skill](https://agentskills.io)。**一个 skill 装下全部娱乐玩法**——装一遍就够。

## fun-pack（娱乐大礼包）

四大块，一个 [`fun-pack`](skills/fun-pack/) 全包了：

| 块 | 触发示例 | 玩法 |
|----|---------|------|
| **A 持续·加一句** | `开启激励模式` / `开启押韵模式` / `关闭X` | 8 频道可独立开关、可叠加：**激励 / 丧(消极) / 废话文学 / 押韵 / 经典台词 / 歌词 / 古诗词 / 古文**，回复开头或末尾加一句点缀 |
| **B 持续·变语气** | `开启角色模式 猫娘` / `开启方言模式 东北话` | 整段用指定**角色/方言口吻**说话 |
| **C 点播** | `讲个笑话` / `来句土味情话` / `来个冷知识` | 点一次给一个：干净笑话 / 土味情话 / 真实冷知识 |
| **D 🔞 成人开车点播** | `开个车` / `开车` | **18+** 表面正经、通篇双关的连续叙事，点一次给一段 |

**贯穿三块的底线**：🚑 用户真情绪低落时所有娱乐一律让位、好好回应；绝不主动、隔离不干扰正文；真实类频道（台词/歌词/诗词/古文）严格只引真实原句；成人块守满未成年/非自愿/歧视/重口/真人五条红线（均含"别误杀"判据）。

## 安装

```bash
git clone https://github.com/SymbolLong/sl-skill.git
cp -r sl-skill/skills/fun-pack ~/.claude/skills/
```

装好后重启 / 新开对话即可。

## 用法示例

```
你：开启激励模式          # 持续模式，可叠加多个频道
Claude：✅ 激励模式已开启（随机风格）……

你：帮我看下这段代码
Claude：💪 这点 bug 算什么，冲！

      好的，这段代码……

你：讲个笑话              # 点播干净笑话
Claude：😄 为什么青蛙能跳得比树还高？——因为树根本不会跳。

你：开个车 修水管的        # 🔞 点播成人双关（18+）
Claude：🔞 ……（一段表面正经、暗指另一回事的叙事）
```
