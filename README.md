# sl-skill

自用 & 供大家娱乐的 [Claude Code / Agent Skill](https://agentskills.io)。
**一个 `sl-fun-pack` 装下全部娱乐玩法——装一遍就够。**

> ⚠️ 含一块 **18+ 成人向**内容（`开个车`），仅在你主动触发时才出现。介意请勿安装。

---

## 🎁 五大块

| 块 | 触发示例 | 玩法 |
|----|---------|------|
| **A 持续·加一句** | `开启激励模式`、`开启诗词模式`、`关闭X` | 8 个可独立开关、可叠加的点缀频道，在回复开头/末尾加一句 |
| **B 持续·变语气** | `开启角色模式 猫娘`、`开启方言模式 东北话` | 整段用指定**角色 / 方言口吻**说话（可叠加成"东北话毒舌管家"） |
| **C 点播** | `讲个笑话`、`来句土味情话`、`来个冷知识` | 点一次给一个：干净笑话 / 土味情话 / 真实冷知识 |
| **D 🔞 开个车** | `开个车 修水管的` | **18+** 表面正经、通篇双关的连续叙事 |
| **E 忙碌模式** | `BM-20m <话题>` / `BM-1h <话题>`（继续 `BM+30m`） | 工作演技：像真在攻坚一样一阵阵真做事（建目录/写文档/跑命令）、后台计时摊满目标时长，完事出纪要。**码式触发，连命令都不穿帮** |

**A 块 8 频道**（触发都是「开启+两字+模式」）：激励 💪 / 丧 🥀 / 废话 / 押韵 / 台词 / 歌词 / 诗词 / 古文。开头（激励·丧）二选一，末尾（其余）可叠加。

## 🚀 安装

```bash
git clone https://github.com/SymbolLong/sl-skill.git
cp -r sl-skill/skills/sl-fun-pack ~/.claude/skills/
```

重启 / 新开对话即可。想用哪块就说对应触发语；全程**用户不触发就绝不主动**。

## 💬 用法示例

```
你：开启激励模式          # 持续频道，可叠加多个
Claude：✅ 激励模式已开启……

你：帮我看下这段代码
Claude：💪 这点 bug 算什么，冲！

      好的，这段代码……

你：开启方言模式 东北话    # 变语气，整段变味但内容照样准
你：讲个笑话              # 点播
Claude：😄 青蛙为啥跳得比树高？——树根本不会跳。

你：BM-1h 分库分表        # 工作演技：一阵阵真做事、后台计时摊满 1 小时，命令本身不穿帮
你：BM+30m                 # 给同话题再续一程时长，续写纪要
```

## 🛡️ 安全与边界（写进 skill、别人装了也生效）

- 🚑 **总安全阀**：你**真的**情绪低落时，所有娱乐一律让位——不抖机灵、好好回应，需要时给求助渠道。图一乐永远让位于一个真的不好受的人。
- **绝不主动 · 隔离**：所有玩法必须你明确触发；点缀/段子独立成段、不干扰正经回答。
- **真实类只引真的**：台词 / 歌词 / 诗词 / 古文 / 冷知识**只给确有其事的原句/真事**，记不清就坦白、绝不瞎编（也不过度自我怀疑到啥都不敢给）。
- **🔞 开个车的五条红线**（均含"别误杀"判据）：未成年 / 非自愿 / 歧视物化 / 重口 / 真人性化，一律不碰；正常的成人玩笑不误杀。
- **忙碌模式**：图一乐的演技，一阵阵真做事、后台计时摊满时长、用最便宜的 Haiku 省 token；别拿去做严肃造假。
