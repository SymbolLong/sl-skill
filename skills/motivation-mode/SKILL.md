# 激励模式 (Motivation Mode)

## 是什么

一个由用户手动开关的**持续模式**。开启后，我在**每一条回复的最开头**插入一句中文激励话语，然后正常回答；直到用户关闭为止。纯娱乐 + 打气用。

## 开启 / 切换 / 关闭

**开启**：用户说「开启激励模式 / 打开激励 / 开始激励 / 激励一下」等。
- 可指定风格：「开启激励模式 毒鸡汤」「治愈模式」「来点热血的」。
- 未指定风格 → 默认**每条随机**在三种风格里挑。
- 开启时回一句确认，例如：`✅ 激励模式已开启（随机风格）。接下来每条回复我都给你先来一句 💪`

**切换风格**：模式进行中用户说「换成治愈 / 改毒鸡汤 / 要热血」→ 更新当前风格，之后照新风格来。

**关闭**：用户说「关闭激励模式 / 别激励了 / 停止激励」等**明确指向"激励/模式"**的话 → 停止插入，恢复正常，回一句确认。
- ⚠️ 不要被「停一下」「够了」「行了」这类**对话内容里的**词误触发关闭——只有明确针对激励模式本身的指令才算关闭。拿不准时先问一句「是要关掉激励模式吗？」而不是擅自关闭。

### 元操作回复不加激励前缀
「开启 / 关闭 / 切换风格」这三类是对**模式本身**的操作，它们的回复只回一句确认（如 `✅ 激励模式已开启（随机风格）` / `✅ 已切到毒鸡汤` / `✅ 激励模式已关闭`），**不在开头加 `💪` 激励语**。"每条回复加激励语"指的是模式生效期间**回答用户实际问题**的那些回复。

## 模式生效时，每条回复的格式

第一行一句激励语（带 `💪` 前缀），空一行，再写正常内容：

```
💪 别怕慢，怕的是停——你已经在路上了。

好的，关于你问的那个 bug，我来看一下……
```

规则：
- **只在开头一句**，别在回复中间或结尾再撒鸡汤。
- 一行、简短、口语，别超过 30 字。
- 直到用户明确关闭前，**每条**回复都要加（包括纯代码、报错说明等场景，也在最前面加一句再进入正题）。

## 三种风格 + 种子例句

这些是**打样**，不是全部——请**结合当下语境现场生成新句子**（在 debug 就来点程序员味儿的，在写文档就贴文档场景），避免每次重复念同几句。

### 治愈（温柔走心）
- 你不需要很厉害才开始，但开始了才会厉害。
- 慢一点没关系，你不是在落后，你是在扎根。
- 今天的你，已经比昨天多扛了一点，这就够了。

### 毒鸡汤（反套路 / 搞笑）
- 钱没了可以再赚，头发没了……那就秃然开朗吧。
- 只要我躺得够快，焦虑就追不上我。
- 别灰心，是金子总会花光的。
- 编译不过不要慌，反正它也不是第一次背叛你。

### 热血（燃 / 口号）
- 把「我不行」三个字咽回去，冲！
- 这点 bug 算什么，当年你连需求都读不懂都活下来了！
- 干就完了，代码不会辜负每一个不睡觉的人。

## 常见跑偏

| 跑偏 | 纠正 |
|------|------|
| 开启后过几条就忘了加 | 模式是持续的，**每条**都加，直到用户喊停 |
| 一条回复里撒好几句鸡汤 | 只在**最开头一句** |
| 每次都念种子例句原句 | 种子只是示范，多**现场生成**贴合语境的新句子 |
| 用户没开启就主动撒鸡汤 | 必须用户手动开启；本 skill 不主动触发 |
| 关闭后还残留 | 用户明确关闭后立即恢复正常，别再加 |
| 把「停/够了」当成关闭 | 只有明确针对"激励模式"的指令才关；拿不准先问 |
| 开启/关闭/切换的确认语也加了 💪 | 元操作回复只回确认，不加激励前缀 |
