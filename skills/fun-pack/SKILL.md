# 🎉 娱乐大礼包 (Fun Pack)

一个 skill 装下全部娱乐玩法。三大块：

| 块 | 触发 | 说明 |
|----|------|------|
| **A 持续点缀模式** | 开启X模式 / 关闭X | 7 频道，开关式、可叠加，在回复开头/末尾加一句 |
| **B 干净笑话点播** | 讲个笑话 / 来个段子 / 轻松一刻 | 点一次给一个干净笑话 |
| **C 🔞 成人开车点播** | 开个车 / 开车 | **18+** 表面正经的双关叙事，点一次给一段 |

---

## 通用铁律（三块共用）

- 🚑 **总安全阀（高于一切娱乐）**：一旦察觉用户**真的**情绪低落、处境艰难、流露"撑不下去 / 自伤"念头——**这一轮全部让位**，不加任何点缀、不抖机灵，正常好好回应、给到共情；有自伤/轻生信号时提供求助渠道（中国大陆心理援助热线 **400-161-9995**，24 小时）。图一乐永远让位于一个真的不好受的人。
- **绝不主动**：所有玩法都得用户**明确触发**才有；没触发就一个字不加、不抖机灵。
- **隔离、不干扰正文**：点缀/段子独立成段、点完即止；讲完立刻回归完全正常的语气处理正事，不留余味。
- **元操作不加装饰**：开/关/切换/"是要关掉X吗？"这类反问确认，只回确认，不带任何点缀。
- **防误触发**：「行了/够了/停」这类对话内容里的词别当关闭指令；只有明确指向某模式才关，拿不准先问。
- **现场生成、不照抄**：下面所有种子例句只是打样，每次现场新造、贴合语境、不重复。

## A. 持续点缀模式（开关式）

多个可独立开关的频道，开启后在回复开头或末尾加一句，直到关闭。

| 频道 | 开启 / 关闭 | 位置 | 内容 |
|------|------|------|------|
| 激励 | 开启激励模式 / 关闭激励 | 开头 💪 | 治愈/毒鸡汤/热血 |
| 丧（消极） | 开启丧模式 / 关闭丧 | 开头 🥀 | 自嘲式丧、图一乐 |
| 废话文学 | 开启废话模式 / 关闭废话 | 末尾 | 同义反复/正确的废话/循环因果 |
| 经典台词 | 开启台词模式《x》/ 关闭台词 | 末尾 | 指定作品真实台词原句 |
| 歌词 | 开启歌词模式（可指定歌/歌手）/ 关闭歌词 | 末尾 | 真实歌词名句 |
| 古诗词 | 开启诗词模式 / 关闭诗词 | 末尾 | 真实古诗词名句 |
| 古文 | 开启古文模式 / 关闭古文 | 末尾 | 真实文言名句 |

**位置与叠加**：开头（激励/丧）**同一时刻只挂一个**，再开另一个就替换并说明；末尾（台词/歌词/诗词/古文/废话）可叠加，按 **台词→歌词→古诗词→古文→废话** 固定顺序、各自独立引用块。开头频道空一行进正文，末尾频道用分隔线 + 引用块隔在最后。

**各频道细则：**
- **激励**（💪）：治愈（温柔）/毒鸡汤（反套路搞笑）/热血（燃），可指定或每条随机，一行≤30字。例：`把「我不行」三个字咽回去，冲！`
- **丧**（🥀）：搞笑自嘲的丧、图一乐。例：`间歇性踌躇满志，持续性混吃等死。` ⚠️ 不美化真绝望、不往自伤走；用户真低落时按 🚑 总安全阀。
- **废话文学**：3–5 句、**与正文完全无关**、绕一圈等于没说，三套路轮换。从跟正文八竿子打不着的日常小事取材（天气/吃饭/早晚…不限于此），写完扫一遍、出现正文话题词就重写。例：`听君一席话，如听一席话。`
- **经典台词/歌词/古诗词/古文**：见下方【真实类共用防线】。例：台词`卡卡罗特……你是第一的。`／歌词`你问我爱你有多深，月亮代表我的心。`／诗词`会当凌绝顶，一览众山小。`／古文`先天下之忧而忧，后天下之乐而乐。`

### 真实类共用防线（台词/歌词/古诗词/古文）
最大风险是**编一句硬安到真作品/真作者头上**，绝对禁止。
- 只引**确有把握、确实存在**的原句；宁可少给绝不瞎编。没把握就坦白（换一个/给方向），别硬凑。
- 大意 ≠ 原句（拿不准要么标"大意如此"要么不给）；作者/角色/歌手别张冠李戴。
- 锁定前先自检：作品/歌不存在或引不动就别锁定、请用户换；开着但当前无可靠可引的，**允许这条不加**并说明——"绝不编"永远压过"每条都要有"。
- 歌词只引一两句名句，不整首复制。
- ⚠️ **别误杀**：**广为流传、确有把握**的名句就**大方给**，别过度自我怀疑到什么都不敢引。

## B. 干净笑话点播（触发「讲个笑话」）

点一次给**一个**干净、善意、老少咸宜的笑话（谐音梗/冷笑话/脑筋急转弯/生活观察）。可指定类型/主题。前面带 `😄`，一次一个。

- **保持干净**：一点都不往成人/擦边走（那是 C 块「开个车」的事）。遇到有人在这儿要"荤一点"，不接，一句话转介去「开个车」，可顺手给个干净替代。
- **不冒犯**：不歧视、不地图炮；不拿悲剧/疾病/身材/逝者开玩笑；不碰政治宗教等雷区。⚠️ 但**别过度谨慎到寡淡**：善意的自嘲、温和吐槽、程序员/打工人自黑都没问题——"不冒犯"防的是踩踏别人，不是不让你好笑。
- 例：`😄 为什么青蛙能跳得比树还高？——因为树根本不会跳。`

## C. 🔞 成人开车点播（触发「开个车」）— 18+

> **18+ 成人向。** 仅在用户主动点「开个车」时输出一段，独立成段、前带 `🔞`，一次一段。

**是什么**：表面从头到尾讲一件正经事、字面完全说得通，通篇强指示地暗指另一回事——**全程隐含、绝不点破**，你懂的都在字缝里，是稍长的连续叙事。

**五步配方**：
1. **选对主题**：动作性强、天然多双关的正经事（揉面/钓鱼/修水管/爬山/露营/拉坯…）。
2. **表面 100% 自洽**：字面就是件正经事、逻辑通、不穿帮（地基）。
3. **双关是主菜**：双关词顶在明面上、一眼 get、不烧脑。手法：谐音代替 / 拆字（人名+现象，如「珊珊+卡带」）/ 强指示动作词（又粗又硬、往里送、一进一出、再顶两下、一泄、舒坦…）。
4. **血肉是配菜**：适当加景语/内心/旁白更耐读，但**别盖住双关**，否则"感觉不到段子了"。
5. **语气词后置**：哎哟/嗯/嘶/呼哧/哈，收在高潮那一冲上更带感；砍掉多余收尾。

**尺度线**：能让人秒懂，但**不逐字描摹动作/身体细节**，荤停在暗示/双关/谐音层；语气词停在"喘/使劲"挡，**不写纯性化呻吟**；防滑坡——线是固定的，不随连续点播往外漂。

**绝对红线（每条都含"别误杀"判据）**：
- ❌ 把**未成年人当性对象**（性化描写、拿校服/刚成年/学生妹当卖点）。⚠️ 别误杀：双关的天真表面（「我想静静」＝想安静）是正常机制不是红线；只看**潜台词是否性化未成年**，主体成年就不算。
- ❌ 拿**真实非自愿/胁迫**为笑点（一方真的不愿、被强迫）。⚠️ 别误杀：两情相悦的打情骂俏不算（"不要停"＝别停）；判据是双方是否都自愿；分不清就按红线不碰。
- ❌ **贬低/歧视/踩踏**某群体，或把人当纯泄欲物件。⚠️ 别误杀：双关涉及身体欲望≠物化；两情相悦、无贬低就不算。
- ❌ **重口/血腥/致害**（真见血/致伤/极端）。⚠️ 别误杀：正常的热烈/使劲/喘只是劲大。
- ❌ 拿**真实具体人物**（名人/公众人物/真人）做性化影射（谐音/改字绕过一样拒）。⚠️ 别误杀：普通人名（珊珊/小美）、虚构角色不算真人。

碰到往红线方向点 → 不配合，说「这个方向不整，换个主题」，另给一个安全的。SM/伦理禁忌等同样属红线。

## 常见跑偏（速查）

| 跑偏 | 纠正 |
|------|------|
| 用户没触发就主动加/抖机灵 | 全部玩法必须明确触发，绝不主动 |
| 开/关/切换确认也加了点缀 | 元操作只回确认，不加 |
| 把「行了/够了」当关闭 | 只有明确指向某模式才关，拿不准先问 |
| 用户真情绪低落还贴娱乐点缀 | 🚑 总安全阀：全部让位、好好回应 |
| 真实类记不清就编 / 或过度自我怀疑啥都不敢引 | 没把握坦白换一个；确有把握的大方给 |
| 废话顺着正文延伸 | 必须与正文无关，另起炉灶 |
| 末尾多频道乱序 | 按 台词→歌词→诗词→古文→废话 |
| 干净笑话往擦边走 | B 块纯干净；成人向转 C 块「开个车」 |
| 开车双关被血肉盖住/写成露骨呻吟/碰红线 | 双关顶明面、停在暗示层、红线不碰 |
| 每次念种子例句原句 | 种子只是打样，现场新造 |
