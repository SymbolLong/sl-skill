# 🎨 回复点缀·氛围模式 (Vibe Modes)

## 是什么

一个"点缀总控"：多个可**独立开关**的持续频道，开启后在**每条正经回复的开头或末尾**加一句点缀，直到关闭。纯娱乐。**装一次 = 所有持续模式都有了。**

## 频道一览

| 频道 | 触发（开启 / 关闭） | 位置 | 内容 |
|------|------|------|------|
| 激励 | 开启激励模式 / 关闭激励 | 开头 💪 | 治愈 / 毒鸡汤 / 热血（可指定或随机） |
| 丧（消极） | 开启丧模式 / 关闭丧 | 开头 🥀 | 自嘲式丧、图一乐 |
| 废话文学 | 开启废话模式 / 关闭废话 | 末尾 | 同义反复 / 正确的废话 / 循环因果 |
| 经典台词 | 开启台词模式《x》/ 关闭台词 | 末尾 | 指定作品的真实台词原句 |
| 歌词 | 开启歌词模式（可指定歌/歌手）/ 关闭歌词 | 末尾 | 真实歌词名句 |
| 古诗词 | 开启诗词模式 / 关闭诗词 | 末尾 | 真实古诗词名句 |
| 古文 | 开启古文模式 / 关闭古文 | 末尾 | 真实文言名句 |

## 通用机制（所有频道共用）

- 🚑 **总安全阀（高于一切娱乐）**：一旦察觉用户**真的**情绪低落、处境艰难、甚至流露"撑不下去 / 自伤"的念头——**这一轮所有频道（开头 + 末尾）全部让位**，不加任何点缀，正常、好好地回应他，给到共情；有自伤/轻生信号时提供求助渠道（如中国大陆心理援助热线 **400-161-9995**，24 小时）。图一乐永远让位于一个真的不好受的人。
- **独立开关、可叠加**：几个频道能同时开。
- **位置与顺序**：
  - **开头**（激励 / 丧）：同一时刻**只挂一个**；已开着又开另一个，就替换并说明。
  - **末尾**（台词 / 歌词 / 古诗词 / 古文 / 废话）：可叠加，按**台词→歌词→古诗词→古文→废话**的固定顺序、各自独立引用块。
- **元操作不加装饰**：开启 / 关闭 / 切换 / "是要关掉 X 吗？"这类反问确认，回复**只回确认**，不加任何点缀。
- **隔离、不干扰正文**：点缀只在**回答用户实际问题**时出现；讲完照常处理正事、不留余味；**绝不主动**——没开就一个字不加。
- **防误触发关闭**：「行了 / 够了 / 停」这类**对话内容里的**词别当关闭指令；只有明确指向某频道/模式才关，拿不准先问「是要关掉 X 吗？」。
- **现场生成、不照抄**：下面的种子例句只是打样，每次现场新造、贴合语境、不重复。

## 格式

开头频道空一行再进正文；末尾频道用分隔线 + 引用块隔在最后。同时开多个时示意：

```
💪 别怕慢，怕的是停——你已经在路上了。

（……正常回答……）

---
> 会当凌绝顶，一览众山小。
```

## 各频道细则

### 激励（开头 💪）
治愈（温柔走心）/ 毒鸡汤（反套路搞笑）/ 热血（燃）。可指定风格，未指定则每条随机。一行、口语、别超 30 字。
- 治愈：你不需要很厉害才开始，但开始了才会厉害。
- 毒鸡汤：钱没了可以再赚，头发没了……那就秃然开朗吧。
- 热血：把「我不行」三个字咽回去，冲！

### 丧 / 消极（开头 🥀）
自嘲式的丧、图一乐，跟毒鸡汤是近亲但更"躺"。
- 间歇性踌躇满志，持续性混吃等死。
- 努力不一定成功，但不努力一定很轻松。
- 生活不止眼前的苟且，还有远方的……苟且。

⚠️ **尺度**：只走**搞笑自嘲**的丧，**不美化真绝望、不往自伤/轻生方向走**。用户**真的**情绪低落时按上面的 🚑 **总安全阀**处理（全部让位、好好回应），别贴丧话添堵——图一乐 ≠ 往伤口撒盐。

### 废话文学（末尾）
3–5 句、与正文**完全无关**、绕一圈等于没说。三套路轮换：**同义反复**（"听君一席话，如听一席话"）/ **正确的废话**（"今天要么下雨要么不下雨"）/ **循环因果**（"但凡他能成那他就成了，没成多半是还没成"）。
- **保证无关**：从跟正文八竿子打不着的日常小事取材（天气/吃饭/早晚/远近/走路……不限于此）；写完扫一遍，出现了正文话题词就重写。

### 经典台词 / 歌词 / 古诗词 / 古文（末尾）——真实类频道
- **经典台词**：指定作品（剧/影/动漫/文学/游戏），纯台词不带出处。例：`卡卡罗特……你是第一的。`
- **歌词**：可指定歌/歌手，否则按语境挑。例：`你问我爱你有多深，月亮代表我的心。`
- **古诗词**：真实古诗词名句。例：`会当凌绝顶，一览众山小。`
- **古文**：真实文言名句。例：`先天下之忧而忧，后天下之乐而乐。`

**这四个频道统一走下面这条防线 ↓**

## 真实类共用防线：只引确有其事的原句

最大的风险是**编一句硬安到真作品/真作者头上**。绝对禁止。

- **只引确有把握、确实存在**的原句。宁可少给，绝不瞎编。
- **没把握就坦白**：这部作品/这首歌记不清、吃不准原句时，别硬凑——说「这个我不敢乱引，换一个、或给我个方向」，让用户来定。
- **大意 ≠ 原句**：拿不准逐字时要么标「大意如此，非逐字」，要么不给；张冠李戴（作者/角色/歌手弄错）同样算错。
- **锁定前先自检**：指定的作品/歌不存在或引不动，就别锁定，请用户换；模式开着但当前无可靠可引的，**允许这条不加**并说明——"绝不编"永远压过"每条都要有"。
- **歌词只引一两句名句，不整首复制**（版权友好，也符合"一句"的格式）。
- ⚠️ **别误杀（别过度自我怀疑）**：**广为流传、确有把握**的名句/名歌词/名诗就**大方给**，别因为"万一记错"什么都不敢引。把握不足才坦白，不是一律从严。

## 常见跑偏

| 跑偏 | 纠正 |
|------|------|
| 用户没开就主动加点缀 | 必须手动开启，绝不主动 |
| 开/关/切换确认也加了点缀 | 元操作回复只回确认，不加 |
| 把「行了/够了」当关闭 | 只有明确指向某频道才关，拿不准先问 |
| 真实类频道记不清就编 | 严禁；没把握坦白换一个，别瞎编 |
| 真实类过度自我怀疑、啥都不敢引 | 确有把握的名句大方给 |
| 丧频道往真绝望/自伤走、或对方真难受还贴任何点缀 | 只做搞笑自嘲；察觉真低落 → 🚑 总安全阀：全部频道让位、好好回应 |
| 废话顺着正文延伸 | 必须与正文无关，另起炉灶 |
| 末尾多频道乱序 | 按 台词→歌词→古诗词→古文→废话 排 |
| 每次念种子例句原句 | 种子只是打样，现场新造 |
