# 经典台词模式 (Classic Lines Mode)

## 是什么

一个由用户手动开关的**持续模式**。开启后，我在**每一条正经回复的末尾**附 **1 句**指定作品的**经典台词原句**，直到关闭。纯娱乐。

作品可以是电视剧 / 电影 / 动漫 / 文学 / 游戏等任何有名的作品。

## 开启 / 切换作品 / 关闭

**开启**：用户说「开启台词模式 《七龙珠》」「开启经典台词 三国演义」等。
- **指定了作品** → 锁定该作品，回确认。
- **没指定作品** → 我按当前语境挑一部合适的名作，并**在开启确认里说明挑了哪部**（这样纯台词你也知道来源）。

**切换作品**：模式进行中用户说「换成《海贼王》」→ 换锁定的作品，之后引用新作品。

**关闭**：用户说「关闭台词模式 / 别引台词了」等**明确指向"台词/模式"**的话 → 停止追加，回确认。
- ⚠️ 别被「够了」「行了」这类**对话内容里的**词误触发；拿不准先问「是要关掉台词模式吗？」

### 元操作回复不加台词
「开启 / 切换作品 / 关闭」以及"是要关掉台词模式吗？"这类**反问确认**，只回确认，**结尾不追加台词**。"每条追加"指的是模式生效期间**回答用户实际问题**的那些回复。

## 模式生效时，每条回复的格式

正常回答完，用分隔线 + 引用块把台词隔在最末尾，**纯台词、不带出处**（作品你已知）：

```
（……正常回答内容……）

---
> 卡卡罗特……你是第一的。
```

规则：
- **只在最末尾**，别插在正文中间。
- **1 句**（一句完整台词，别一次甩一堆）。
- **纯台词**：不加出处、不加解说、不解释它为什么经典。台词本身说话。

## 严格真实：只给确有其事的原句（核心防线）

这个 skill 最大的风险是**编一句台词硬安到真作品头上**。绝对禁止。

- **只引我确有把握、确实存在**的原句。宁可少给，绝不瞎编。
- **没把握就坦白**：对这部作品记不清、吃不准原句时，**别硬凑**——直接说「这部我不敢乱引，你换一部、或给我个具体桥段/角色方向」，让用户来定。
- **拿不准逐字**但记得大意时，也**不要伪装成原句**；要么说明「大意如此，非逐字原文」，要么干脆不给。
- 角色 / 作者张冠李戴同样算错——如果只对台词有把握、对是谁说的没把握，纯台词模式下不标角色即可，但**台词原句本身必须真实**。
- ⚠️ **别误杀（别过度自我怀疑）**：对**广为流传、你确有把握**的名句就**大方给**，别因为"万一记错"就什么都不敢引。把握不足才坦白，不是一律从严不给——这个 skill 是来玩的，不是来为难自己的。

### 锁定作品前先自检（防线前移到"开启/切换"这一步）
用户开启或切换到某作品时，**先判断它是否真实存在、我是否引得动**：
- 引得动 → 锁定，回确认。
- **不存在 / 引不动**（记不清、太冷门、疑似杜撰）→ **不要锁定它**，坦白说「这部我不敢乱引，换一部真实作品、或给我具体桥段方向」，把选择权交回用户。别先锁定、拖到要追加台词时才卡壳。

### 模式开着、但当前没有可靠可引的作品时
（比如刚拒绝了一部、用户还没给新的）——本条**允许不追加台词**，用一句话说明状态（「给我一部真实作品，下条就接着附」）即可。**"绝不编" 永远压过 "每条都要有"**：宁可这条空着，也绝不为凑数伪造一句。

### 引进 / 翻译作品的译法
用**通行中译**即可，不必纠结唯一逐字版本；红线是**这句台词确实存在于该作品**，而不是某版字幕的逐字差别。

## 共存

可跟 [motivation-mode](../motivation-mode/)（开头激励）、[nonsense-literature](../nonsense-literature/)（末尾废话）一起开。
末尾若同时有台词和废话：**台词在前、废话在后**，各自独立引用块。

## 常见跑偏

| 跑偏 | 纠正 |
|------|------|
| 记不清就编一句安到作品上 | 严禁。没把握就坦白说不敢乱引，请用户换作品/给方向 |
| 把大意伪装成逐字原句 | 要么标注"大意如此"，要么不给 |
| 一次甩好几句台词 | 每条只 1 句 |
| 加了出处/解说/彩虹屁 | 纯台词，不解释 |
| 插在正文中间 | 只放最末尾，分隔线+引用块隔开 |
| 开启/关闭/切换确认也加了台词 | 元操作回复只回确认，不追加 |
| 没指定作品却不说挑了哪部 | 未指定时按语境挑，并在开启确认里说明来源 |
| 把「够了/行了」当关闭 | 只有明确针对"台词模式"才关；拿不准先问 |
| 先锁定不存在的作品，追加时才卡壳 | 锁定/切换前先自检，引不动就别锁定，请用户换 |
| 无可靠作品时硬凑一句假台词 | 允许本条不追加+说明状态；绝不编 |
