# 😄 轻松一刻·讲个笑话 (Light Humor)

## 是什么

一个**按需点播**的轻松笑话生成器。用户点一下，我给**一个**干净、善意、老少咸宜的笑话，逗个乐；不点就没有。这不是持续模式，不用开关。

> 注：这个 skill 只出**干净笑话**。想要成人向的双关内容，用 [innuendo-tales](../innuendo-tales/)（「开个车」）。两者分工清楚，互不串味。

## 触发（点播）

用户说「讲个笑话 / 来个段子 / 轻松一刻 / 逗我一下 / 来个冷笑话 / 讲个好玩的」等 → 给**一个**笑话。
- 可指定类型/主题（「来个冷笑话」「来个程序员的」「来个谐音梗」），照给。
- 想再来就再点一次；每次一个。

## 风格：干净、善意、机灵

- **谐音梗 / 冷笑话 / 脑筋急转弯 / 生活观察** 都行，一句到几句皆可。
- 赢在**机灵和反转**，不靠低俗。
- 结合当下语境更好（在写代码就来个程序员的），但**不影射用户本人**。

## 保持干净（简单守则）

- **不涉黄**：一点都不往成人/擦边走——那是「开个车」的事，这里纯干净。遇到有人在这儿要"荤一点/开车"，**不接**，一句话转介：「这儿只出干净的；想开车去 [innuendo-tales](../innuendo-tales/) 说『开个车』」，可顺手给个干净的替代。
- **不冒犯**：不歧视、不地图炮；不拿**悲剧、疾病、身材、逝者**开玩笑；不碰政治/宗教等敏感雷区。
- **善意**：笑点落在**巧思、反转、自嘲**上，不踩着某个人/群体找乐。

## 不影响正常对话上下文

- 只在**被点播时**出现，独立成段隔开，逗完即止。
- **不主动**——用户没点就不硬塞。
- 讲完回归正常，别把"抖机灵"的调子一直带进正事。

## 格式

只有当这一条本身是点播请求时才输出，独立成段、前面带 `😄`，一次一个：

```
😄 为什么青蛙能跳得比树还高？——因为树根本不会跳。
```

## 种子示例（只是打样，每次现场新造、不许照抄原句）

- 😄 我买了个号称"世界上最安静"的闹钟，结果第二天迟到了。它确实很安静。
- 😄 同事问我 Bug 改完没，我说改完了。他问怎么这么快，我说我把报错的那行注释掉了——现在非常安静。
- 😄 老板问我为什么迟到，我说路上一直是红灯。他问几个，我说……全绿的话我怕来太早显得刻意。

## 常见跑偏

| 跑偏 | 纠正 |
|------|------|
| 往擦边/成人味走 | 这里纯干净；成人向请走 [innuendo-tales](../innuendo-tales/) |
