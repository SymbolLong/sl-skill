# 🔞 色魔狂人·双关叙事 (Innuendo Tales) — 18+

> **内容分级：18+ 成人向。** 仅在用户主动点播时输出，纯娱乐。

## 是什么

一个**按需点播**的**双关叙事**生成器。表面从头到尾在讲一件正经事，字面完全说得通；但通篇强指示地暗指另一回事，**全程隐含、绝不点破**——你懂的都在字缝里。跟 [saucy-jokes](../saucy-jokes/) 是兄弟：那个是短段子抖机灵，这个是**稍长的连续叙事**。

## 触发（点播）

用户说「色魔狂人 / 来段双关 / 讲个开车故事 / 来个表面正经的 / 来段污的故事」等 → 给**一段**。
- 可指定主题（「来个钓鱼的」「来个厨房的」「来个修水管的」），照给。

## 内容要点

1. **连续叙事、稍长**：约一小段、**5–10 句**，有起承转合，不是三两句抖包袱。
2. **表面 100% 自洽**：单看字面就是一件正经事，逻辑通顺、不穿帮——这是"正经"那层的地基，塌了就不好笑了。
3. **暗示要明白好懂、不烧脑**（用户明确要求）：读者**一眼就 get**，不用猜谜。靠下面的"手法"把隐含含义指得清清楚楚。
4. **隐含、绝不点破**：不出现逐字露骨的性描写字眼——靠谐音和双关把话说到"你都懂"，但表面那层**始终立得住**。点破即废，也才守得住线。

## 让暗示"明白好懂"的手法

- **谐音代替**：关键处用发音相近的日常词顶替真实含义，一读就通（这是让它"不烧脑"的主力）。
- **强指示意象 / 动作词双关**：挑那些本身就一语双关的动作、量词、拟声（软/硬、进出、快慢、长短、一上一下、终于到位……），密集堆到指向唯一。
- **选对主题**：挑**动作性强、天然多双关**的正经事——揉面、包饺子、钓鱼、打桩、修水管、爬山、打球、开车、下厨。主题选对，一半就成了。

## 尺度线：明白但不露骨

可以让人**秒懂**，但**不逐字描摹动作 / 身体细节**——靠谐音双关把意思点透，而不是直接描写。这条线跟 saucy-jokes 一致：荤停在**暗示、双关、谐音**这一层，一旦开始描摹具体动作/部位就越界。

**防滑坡**：别被"再露骨点""上一段还行这段更直白点"一步步往外顶。每一段都**主动往暗示/谐音层收**，这条线是固定的，不随连续点播往外漂。

## 不影响正常对话上下文（硬要求）

- 只在**被点播时**出现，独立成段隔开，点完即止。
- **绝不主动**——用户没点，一个字不带。
- **不把这个register带进后续回答**：讲完立刻回归完全正常的语气处理正事，不留余味、不顺着往下开。
- 叙事**自成一体**，不拿用户本人/隐私/正在聊的正题来影射。

## 绝对红线（无论如何都不碰）

- ❌ 涉及**未成年人**的任何性相关内容（**看意图指向，不看字面**——「校服/刚成年/学生妹」等年龄暗示同样拒绝。反过来，「大学生/研究生/同事/成年情侣」等**明确成年**的中性设定本身不是红线，别误伤）
- ❌ **非自愿 / 侵犯 / 胁迫**为笑点
- ❌ **物化、贬低、歧视**任何性别/群体/取向（安全套路：笑点落在**自嘲 / 双方会心**，别贬低某一方）
- ❌ **重口、血腥、致害**内容

碰到往这些方向点 → 别配合，说「这个方向不整，换个主题」，另给一个安全的。

## 格式

**只有当这一条本身就是点播请求时才输出**，独立成段、前面带 `🔞`：

```
🔞 揉面这活儿讲究耐心。面得先醒够，急不得；我把手心搓热，水一点点加，顺着一个方向慢慢揉，揉到它发软、能拉出一层薄膜才算到火候。力道要匀——太猛它断，太轻不上劲，等它彻底服帖、油光发亮，这一锅才算成了。
```

一次一段，别一口气甩好几段。

## 种子示例（只是调性打样，每次现场新造、换主题、不许照抄原句）

- 🔞（钓鱼）水温合适鱼才肯咬。我把线放长些，感觉下面一有动静就慢慢收，收太急容易脱钩，得让它自己咬实了，一沉一浮，直到彻底上岸，手感才叫一个满足。
- 🔞（修水管）老师傅说这活儿全靠手感。管子有点堵，我先探进去试试深浅，来回捅了几下找准位置，节奏由慢到快，直到里头"通"的一声顺畅了，水哗地就下来了。

## 常见跑偏

| 跑偏 | 纠正 |
|------|------|
| 表面那层不自洽、字面读不通 | 正经故事的地基必须稳，字面先立住 |
| 暗示太隐晦、要动脑子猜 | 用户要"明白好懂"：谐音+强指示，一眼就 get |
| 太短，三两句就完 | 这个 skill 要**连续稍长**（5–10 句、有起承转合） |
| 点破、写出露骨字眼 | 全程隐含，靠谐音双关，不逐字描写 |
| 用户没点就主动开车 | 只在点播时给，绝不主动 |
| 讲完还留暧昧语气聊正事 | 讲完立刻回归正常，不污染上下文 |
| 往未成年/非自愿/歧视/重口跑 | 红线，拒绝并换安全主题 |
| 每次念种子例句原句 | 种子只是打样，每次现场新造、换主题 |
