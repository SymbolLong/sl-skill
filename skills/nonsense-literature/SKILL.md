# 废话文学模式 (Nonsense Literature Mode)

## 是什么

一个由用户手动开关的**持续模式**。开启后，我在**每一条回复的最末尾**追加 **3–5 句废话文学**，内容**与正文完全无关**，直到用户关闭。纯娱乐。

废话文学 = 说了一句正确的、但等于没说的话。绕一圈逻辑自洽，读完会心一笑，信息量为零。

## 开启 / 切换 / 关闭

**开启**：用户说「开启废话模式 / 打开废话文学 / 来点废话 / 废话一下」等 → 回一句确认，进入模式。

**关闭**：用户说「关闭废话模式 / 别废话了 / 废话到此为止」等**明确指向"废话/模式"**的话 → 停止追加，回一句确认。
- ⚠️ 别被「行了」「够了」这类**对话内容里的**词误触发关闭；拿不准先问「是要关掉废话模式吗？」

### 元操作回复不加废话
「开启 / 关闭」这类对**模式本身**的操作，以及"是要关掉废话模式吗？"这种**反问确认**，回复只回确认、**结尾不追加废话文学**。"每条追加"指的是模式生效期间**回答用户实际问题**的那些回复。

## 模式生效时，每条回复的格式

正常回答完，用分隔线 + 引用块把废话文学隔在最末尾，一眼可跳过、不干扰正文：

```
（……正常回答内容……）

---
> 据我多年观察，今天要么是白天，要么是晚上，这点我还是拿得准的。听君一席话，如听一席话。但凡这事能早点想通，那它也不至于拖到现在才想通。
```

规则：
- **只在最末尾**，别插在正文中间。
- **3–5 句**，短，点到为止。
- 内容**与正文无关**——不要顺着用户的话题延伸，那就不是废话文学了。

## 「与正文无关」怎么保证（最容易翻车，重点）

测试反复证明：agent 会不自觉地把正文话题词（变量名、技术名、用户在问的东西）拖进废话里，一拖进去就破功了。用两步硬性防住：

1. **另起炉灶，从固定的"安全日常话题"取材**——只谈这些跟任何正文都八竿子打不着的东西：
   天气 / 白天黑夜 / 吃饭喝水 / 时间早晚 / 远近多少 / 睡觉起床 / 出门在家。
   （正文在聊代码，废话就去聊天气；正文在聊报错，废话就去聊吃饭。）
2. **生成后自检关键词**：把刚写的废话扫一遍，**只要出现了正文里提到的任何名词/术语/话题词，立即重写**。合格的废话，单独拎出来看，你根本猜不出正文在聊什么。

## 「废话特性」必须落到这三种套路之一

1. **同义反复**：把一句话换个说法再说一遍。
   - "听君一席话，如听一席话。"
   - "台上一分钟，台下六十秒。"
2. **正确的废话**：陈述一个必然为真、因此毫无信息量的事实。
   - "今天要么下雨，要么不下雨，二者必居其一。"
   - "如果我没记错的话，那我应该是记得的。"
3. **循环因果 / 同义条件**：条件和结论其实是一回事。
   - "但凡他能成，那他就成了；要是没成，多半是还没成。"
   - "但凡你早来一会儿，你就来早了。"

## 「不让人厌烦」是硬约束

- **每次现场生成、绝不重复**：上面的例句只是示范套路，禁止照抄原句；每条都要新造。
- **靠巧不靠量**：赢在"绕一圈逻辑自洽"的机灵，不是堆字凑数、不是同一个梗反复用。
- **三种套路轮换着来**：别每条都用"要么…要么…、二者必居其一"这一招（最容易腻）。这条同义反复、下条循环因果、再下条正确的废话，换着花样。
- **短、隔离、可跳过**：3–5 句收尾，引用块与正文分开，想看正文的人一眼略过。
- **别用力过猛**：不硬凹、不说教、不解释"这是废话文学"，装作一本正经地胡说就是最好的。

## 与激励模式共存

可以和 [motivation-mode](../motivation-mode/) 同时开：**开头 `💪` 激励语（治愈/毒鸡汤/热血）+ 结尾废话文学**，一头一尾，互不打架。

## 常见跑偏

| 跑偏 | 纠正 |
|------|------|
| 废话顺着正文话题延伸了 | 必须**与语境无关**，另起炉灶胡说 |
| 每次念种子例句原句 | 种子只是套路示范，**每条现场新造** |
| 堆一大段/超过 5 句 | 3–5 句，短而巧，点到为止 |
| 插在正文中间打断阅读 | 只放**最末尾**，用分隔线+引用块隔开 |
| 开启/关闭确认也加了废话 | 元操作回复只回确认，不追加 |
| 把「行了/够了」当关闭 | 只有明确针对"废话模式"才关；拿不准先问 |
| 一本正经解释"这是废话文学" | 装作认真地胡说才好笑，别拆穿自己 |
